# USR-042: Discovery ends in a plan

**Card:** As a founder or PM who ran discovery, I want it to end in one plan of what to
test, when, and what each result means, so that I know my next weeks and what decides
them.

## Acceptance criteria (observable, binary)
- Discovery ends in one discovery plan document.
- The plan has an assumptions table, an experiments table and a week-by-week timeline.
- Each experiment has a decision rule: if it passes, then ...; if it fails, then ....
- Its depth checklist (USR-029) against the alternative's discovery command passes.

## INVEST / size
~1 day.
