# Growth loops

Funnels leak and need constant refilling; **loops compound**, each user's action drives
the next user's acquisition. Based on Brian Balfour / Reforge's growth-loops model.

## When to use
- Planning sustainable growth beyond a one-off launch, after you have real product value (loops amplify value, they don't create it).

## Process
1. Name the **core value action** (tie to the `/odeo:metrics` North Star).
2. **Find the loop:** input -> action -> output -> that output becomes new input. Types: viral (users create/invite), content (user content -> SEO -> users), paid (revenue -> ads -> users), sales.
3. Map one loop end to end; find the **weakest step** (the constraint).
4. **Loop math (rough):** does each turn bring back **> 1** new input? If < 1, it's not a loop yet, fix the constraint or admit it's a funnel.
5. Pick **one** loop to strengthen (not five half-loops).

## Output
One mapped loop + its constraint + the metric that proves it compounds, saved to `docs/`. Pairs with `/odeo:marketing`, `/odeo:metrics`, `/odeo:cohorts`.

## Example (freelancer tool)
```
Loop: freelancer sends a branded invoice -> client sees "made with X" -> some clients
are freelancers -> they sign up -> they send invoices ...
Constraint: the invoice must look great and carry a subtle, non-spammy CTA.
```

## Quality rules
- A loop's output must feed its own input; otherwise it's a funnel, say which it is.
- Strengthen **one** loop; find and fix the constraint. Don't scatter.
- Loops amplify real value/retention (`/odeo:cohorts`); they won't save a leaky product.
